# Expense Tracker CLI

### A simple Python-based expense tracker that helps you manage your daily expenses.

## Overview

Expense Tracker CLI is a lightweight tool that helps users manage their expenses.

It allows users to:
- Track their daily expenses.
- Organize spending by category.
- View basic statistics.

## Features

- Add and manage expenses.
- Organize expenses by category.
- View basic statistics.
- Filter expenses.
- Export expenses to CSV.

More features are coming soon!

## Tech Stack

- **Python:** 3.11+
- **Questionary:** For an interactive CLI interface.

## Installation

Download the latest `.exe` file from [GitHub Releases](https://github.com/travletothefurureprogramming/Expense-Tracker-CLI/releases).

## Installation (For Developers)

### Requirements

- Python 3.10+
- Git

First, clone the repository:

```bash
git clone https://github.com/travletothefurureprogramming/Expense-Tracker-CLI.git
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Finally, run the application:

```bash
python main.py
```

## How to Use

Select an operation from the interactive menu:

1. **Add Expense** – Add a new expense.
2. **View Expenses** – View all saved expenses.
3. **Delete Expense** – Delete an existing expense.
4. **Filter Expenses** – Filter expenses by category.
5. **View Statistics** – View basic expense statistics.
6. **Export to CSV** – Export your expenses to a CSV file.
7. **Exit** – Close the application.
